# Ideen für später (nicht vor Abschluss Phase 3 umsetzen!)

Parkplatz für Feature-Ideen während des Feature-Stopps. Claude Code: Nichts hiervon umsetzen, solange es nicht in einen Arbeitsplan übernommen wurde.

- **KI-optional-Modus / BYO-API-Key:** Alle KI-Funktionen (Zuordnung, Extraktion, Übersetzung, Paraphrase, Methodenprofile, Kriterien-Vorschlag, Schreibwerkstatt) einzeln abschaltbar; ohne hinterlegten Key blendet die UI die Buttons aus und alles läuft manuell – offene Zuordnungen (Themen, Funktion, Kriterien) erscheinen dann als manuelle To-do-Liste in der Anwendung; semantische Suche fällt auf Volltextsuche zurück. Nutzer können eigenen Anthropic-Key hinterlegen. (Relevant für eine spätere Weitergabe an Mitdoktoranden / Vermarktung.)
- **Mandantenfähigkeit:** Mehrbenutzerbetrieb mit getrennten Beständen, falls das Tool an einen kleinen Kreis weitergegeben wird. (Erst nach erfolgreicher Eigen-Nutzung und Klärung Nebentätigkeit.)
- **Buchkapitel als eigener Quellentyp:** `sources` kennt kein Herausgeber-/Buchtitel-Feld, ein Buchkapitel wird deshalb aktuell wie ein ganzes Buch zitiert (fehlt: „In: Hrsg. (Hrsg.), Buchtitel, S. x-y"). Betrifft mind. eine echte Quelle im Bestand (Tornatzky/Fleischer, TOE Framework). Erst sinnvoll, wenn mehr Kapitel-Fälle auftauchen.
- **Autor+Jahr-Suffixe (2023a/b) auch im Fließtext:** Das Literaturverzeichnis (Phase 4, Paket 4) löst mehrere Werke gleichen Autors/Jahres korrekt mit „a"/„b" auf, die In-Text-Zitation (`format_citation`-DB-Funktion) tut das nicht – zwei verschiedene Werke wären im Fließtext ununterscheidbar. Würde die gemeinsame DB-Funktion ändern (wirkt bestandsweit), deshalb nicht nebenbei mitgemacht.
- **Individuelle „Kritische Überprüfung"-Notiz im QS-Workflow:** Das KI-Verzeichnis (Phase 4, Paket 6) beschreibt die Prüfmethode aktuell nur generisch je Aktionstyp. Ein optionales Freitextfeld in `/pruefen` (Phase 3, Paket 6) beim Bestätigen einer KI-Zuordnung/eines Zitats („wie geprüft?") würde das für die Hochschulvorgabe präziser machen - Migration + UI-Änderung an einer bereits abgeschlossenen Ansicht, außerdem keine Notizen für bereits vor Einführung Bestätigtes.
- **Mobiler Seiten-Overflow durch BottomTabBar:** Bei 375px passen die 8 Navigationspunkte nicht nebeneinander, der ganze Body scrollt horizontal statt nur die Nav-Leiste. Reproduzierbar auf jeder Ansicht, nicht neu - erst beheben, wenn es beim echten Arbeiten am Handy tatsächlich stört.
- **Zitations-Prüfbericht für Word-Dokumente:** Word-Datei (ISP/Exposé/Diss-Entwurf) hochladen → Abgleich aller Zitationen gegen die Literaturdatenbank. Prüfungen: Quelle im Bestand vorhanden? Autor/Jahr/Seitenzahl korrekt (Seiten-Offset berücksichtigen)? Wörtliche Zitate im Dokumenttext nachweisbar (String-Verifikation rückwärts)? Zitierte Quellen vollständig im Literaturverzeichnis und umgekehrt (Waisen-Einträge)? Ergebnis: Prüfbericht mit Fundstellen und Korrektur-VORSCHLÄGEN zum einzelnen Übernehmen – kein automatisches stilles Umschreiben des Dokuments (bei Widersprüchen weiß das Tool nicht, ob Text oder Datenbank recht hat).
